To run this project, nagivate to the server folder and  run the command "node server.js." A message will pop up showing that the command was successful. Then, go to localhost:9000 to ensure that the server is running. Lastly, go to the client folder and run the command "npm run dev." You can then open localhost:5173 and you should be able to use the application.
